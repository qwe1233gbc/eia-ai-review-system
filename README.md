## 这是什么

73道判定式环评审核题，在 **Qwen3-8B / 14B / 32B** 三个规模上，对比 **K1（无检索/纯模型）** 与 **K3（领域RAG）** 两种条件下的审核结论质量，研究不同规模 LLM 的**幻觉机制**与**知识库/检索对幻觉的抑制效果**。全套材料（题单、金标、报告文本、知识库索引、提示词、判分协议、运行脚本）已冻结，供复现。

## 铁律

- 看不懂的题不进实验；知识库命不中的题不进实验；AI 不出题不做最终评分
- **冻结后改条件 = 重跑全量**（任何模型/提示词/KB/检索参数改动即视为新实验）
- 不把 LLM 裁判写成人类专家复评（人工复评未完成）
- 不做与正式算法一致的"result-oriented 调检索器"
